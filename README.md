## О проекте

**АС «ТехНорм»** — система, предназначенная для автоматизации создания и ежедневного обновления технической нормативно-справочной информации (НСИ) на производственных предприятиях.

Система решает одну из главных болей российских заводов — **отсутствие актуальной, целостной и автоматически обновляемой НСИ** (нормы времени, нормы расхода материалов, маршрутные технологические карты).

## Основные возможности

- Автоматический импорт данных из Excel, PDF и сканов
- Построение и анализ маршрутных технологических карт с помощью **Process Mining** (Inductive Miner)
- Автоматический расчёт норм времени и норм расхода материалов
- Интерактивный редактор технологических процессов и маршрутных карт
- Версионность и статусы техкарт (черновик / опубликована / архив)
- Журнал расчётов и изменений
- Полноценная система аудита действий пользователей
- Удобный интерфейс технолога-нормировщика

## Технологический стек

- **Фреймворк**: Blazor Web App (Interactive Server) — .NET 9
- **База данных**: PostgreSQL + Entity Framework Core 9
- **Процесс-майнинг**: собственная реализация Inductive Miner
- **Архитектура**: Чистая архитектура + Repository/Service pattern
- **Стилизация**: Tailwind CSS + готовность к MudBlazor
